# Linux Lab Scripts

Колекція Bash-скриптів для лабораторних робіт
з курсу "Системне програмування та адміністрування ОС".

## Вміст

- `count_files.sh` - скрипт для підрахунку файлів у /etc
- `count_files_ext.sh` - розширена версія: файли, директорії та посилання окремо

## Використання

```bash
./count_files.sh
./count_files_ext.sh
```

## Приклад виводу

```text
======================================
Підрахунок файлів у директорії /etc
======================================

Кількість звичайних файлів: 85
```

Число залежить від системи.
